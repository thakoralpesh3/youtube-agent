==============================================================================
📸 AUTOMATIC STORY DROP FOLDER (Instagram, Facebook & WhatsApp Only)
==============================================================================

How it works:
1. Drag and drop any image (.jpg, .png, .webp) or video (.mp4, .mov, .mkv) into this folder.
2. The agent automatically detects it.
3. It immediately uploads the image/video as a Story to:
   - 📸 Instagram Story
   - 📘 Facebook Story
   - 💬 WhatsApp Status / Story
4. It does NOT upload to YouTube (YouTube is completely skipped).
5. Once uploaded, your media is safely archived into the 'completed/' folder.

Optional Custom Caption:
- To use a custom caption, create a text file with the same name.
  Example:
    my_photo.jpg
    my_photo.txt  <- (contains your caption)

Desktop Shortcut:
- You can access this folder directly from your Desktop via the 'Story' shortcut!
